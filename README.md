# Data-Analyst
Sales Data Analysis and prediction using Python,Power BI,Excel.

Week 4 – Data Analyst Internship

Project Title

Sales Data Analysis and Prediction

Project Overview

This project focuses on analysing business sales data using Python, Excel and Power BI.

The main objective is to understand sales performance, identify important business insights and predict sales using a machine learning regression model.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Microsoft Excel
- Power BI

Project Tasks

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Sales Prediction using Random Forest Regression
4. Excel Data Analysis
5. Power BI Dashboard Creation
6. Findings and Recommendations

Dataset Information

- Total Records: 700
- Total Columns: 16
- Countries: 5
- Products: 6
- Time Period: 2013–2014

Key Analysis

- Country-wise Sales Analysis
- Product-wise Sales Analysis
- Profit Analysis
- Monthly Sales Trends
- Sales Prediction

Conclusion

This project helped me understand data cleaning, data analysis, machine learning and data visualisation using different data analytics tools.
